# spacetimedb-site — Guestbook

A minimal real-time guestbook: a SpacetimeDB **TypeScript module** (`server/`) and a
**Vite + TypeScript** client (`client/`). Anyone connected sees new signatures appear live.

```
server/                 SpacetimeDB module (tables + reducers)
  src/index.ts          user + message tables, setName + sendMessage reducers
client/                 Vite site
  src/main.ts           connect, subscribe, render, call reducers
  src/module_bindings/  GENERATED by `spacetime generate` — do not edit
spacetime.json          module-path + target server (local)
spacetime.local.json    database name (guestbook)
```

## Setup

Built against `spacetime` **2.6.1**. Note: this CLI uses `--module-path`, **not**
`--project-path` (an older flag name).

```bash
# 1. Local SpacetimeDB host — leave running in its own terminal tab
spacetime start

# 2. In a second tab: install module deps + publish
cd server && npm install && cd ..
spacetime publish --server local --module-path server guestbook --yes

# 3. Generate client bindings (client won't compile without this)
mkdir -p client/src/module_bindings
spacetime generate --lang typescript --out-dir client/src/module_bindings --module-path server

# 4. Run the site
cd client && npm install && npm run dev   # http://localhost:5173
```

After editing `server/src/index.ts`, re-run steps 2 and 3 to republish and regenerate
bindings. `spacetime dev` can automate that watch loop.

## Inspect the database

```bash
spacetime sql guestbook "SELECT * FROM message"
spacetime logs guestbook -f
```
